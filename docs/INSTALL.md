# Установка и подключение

## 1. Состав файлов

- `index.html` — разметка доски и скрытая кнопка `interactionButton`.
- `script.js` — логика рендеринга и взаимодействия.
- `style.css` — стили.

## 2. Требования

- Платформа «1С:Предприятие» **8.3.27** и выше.
- Режим клиента: тонкий или веб-клиент.
- Права пользователя: чтение справочника задач и доступ к форме с HTML-полем.

## 3. Способ подключения

1. Добавьте в конфигурацию обработку, в макеты добавить двоичные данные с содержимым `index.html`, `script.js` и `style.css`.
2. Добавьте на требуемую форму поле HTML-документа, реализуйте чтение данных из макетов.
3. В модуле формы реализуйте обработчик `ПриНажатии` для поля HTML-документа.

## 4. Обработка события `ПриНажатии`

Скрытая кнопка `interactionButton` в HTML-разметке служит для передачи управления из JavaScript в код 1С.

**Пример обработчика в модуле формы:**

```bsl
&НаКлиенте
Процедура HTMLПолеПриНажатии(Элемент, ДанныеСобытия, СтандартнаяОбработка)
    // Получаем данные, переданные из JavaScript
    // Например, через параметр ДанныеСобытия или через дополнительное скрытое поле
    ОбработатьДействиеНаДоске(ДанныеСобытия);
КонецПроцедуры
```

> **Примечание:** Точный способ передачи данных (через параметр события или через дополнительное скрытое поле) зависит от вашей реализации. Убедитесь, что JavaScript передаёт необходимые сведения (например, ID задачи, новый статус) в момент вызова `interactionButton.click()`.

## 5. Проверка

1. Откройте доску.
2. Убедитесь, что колонки и задачи загрузились.
3. Перетащите задачу в другую колонку.
4. Проверьте, что в 1С сработал обработчик `ПриНажатии` и изменение сохранилось.
